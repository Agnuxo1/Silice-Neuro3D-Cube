# NUMBERS.md: source of every number in `paper.tex`

Every number in the text and in the hand-written tables of `paper.tex` is listed with its value and the repository file (and key path, table or line) it comes from. Paths are relative to the repository root. Rounded values are rounded from the cited source; values marked **derived** are arithmetic on cited values, with the formula given. Numbers that only appear in generated material have a global source:

- `tables/tab_claims.tex`: verbatim from `Docs/CIERRE-20261012/CLAIMS-LEDGER-20261013-final.json` (generated by `make_tables.py`).
- `tables/tab_protocols.tex`: commits, times and SHA-256 hashes from `resultados/agent/prereg/*_commitment.json`; criteria counts from `resultados/agent/prereg/*_audit.json` (`checks`); attempt-1 status from `resultados/agent/prereg/T25_attempt1_status.json`.
- `references.tex`: volumes, issues, pages, article numbers and years from Crossref `/works/<doi>` records (arXiv API for the three arXiv-only preprints), cached in `paper/full/references_crossref.json`; every DOI or arXiv identifier is listed in `resultados/agent/t26_sota_20261012/verification.json`, `resultados/agent/t24_energy_20261012/sources_verification.json`, or `paper/manuscript.tex` (Clements 2016, Hamerly 2019, McMahon 2023, Horowitz 2014), except Reck 1994 and Saygin 2020, which were added on instruction after a Crossref check.
- Figures: values drawn by `paper/make_figures.py` and `paper/full/make_extra_figures.py` from the JSON files named in their captions.
