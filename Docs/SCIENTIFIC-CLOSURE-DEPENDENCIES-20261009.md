# Evidencia necesaria para cerrar el proyecto

El orden corresponde a las 22 tareas del usuario. Las etapas posteriores
siguen pendientes hasta cerrar la tarea 1. La tabla identifica la evidencia
que hace falta; no declara ejecutados los trabajos futuros ni fija sus
umbrales experimentales. Cada ensayo nuevo requiere protocolo previo.

| Tarea | Evidencia necesaria |
|---|---|
| 1. T96/Q4 | Auditoría temporal de las mallas, convergencia espacial, predicción reservada y dominio. C2-R1 aprobó; M2 conserva 83 campos y su recuperación sigue activa. |
| 2. Barrido modal | Inventario completo, tratamiento de fallos y casos sin selección, residuales y convergencia de modos. |
| 3. Frontera, dominio, campo y fase | Contraste conjunto que conserve el campo complejo y no ajuste la fase para aprobar. |
| 4. Descomposición modal | Balance que incluya interferencias y distinga modos y radiación con una definición justificada. |
| 5. Índices y geometrías medidos | Metrología trazable de muestras y propagación de sus incertidumbres. |
| 6. Contraste vectorial | Resolución electromagnética que incluya polarización y comparación controlada con el modelo escalar. |
| 7. GLASS-006b | Cierre de los controles pendientes del acoplador, con sus fallos históricos conservados. |
| 8. Curvas, cruces y conexiones 3D | Pérdidas y diafonía de componentes calibrados, separadas de pérdidas numéricas de frontera. |
| 9. Escritura profunda y registro | Muestras reales, profundidad medida, alineación entre caras y repetibilidad del proceso. |
| 10. Estabilidad y fase | Errores reales y correlacionados, deriva y límites del control de fase. |
| 11. Compilador a fabricación | Geometrías fabricables, restricciones de máquina y biblioteca de componentes calibrados. |
| 12. Neurona y red funcional | Función completa demostrada, incluyendo detección, control y no linealidad cuando sean necesarias. |
| 13. Fabricación | Muestras de calibración y una red pequeña físicamente realizadas. |
| 14. Medidas ópticas | Pérdidas, modos, polarización, fase y transferencia con instrumentos y calibración. |
| 15. Integración | Óptica, detectores, electrónica y control funcionando como sistema. |
| 16. Tarea independiente | Datos reservados y comparación pertinente, sin ajustar sobre el conjunto de prueba. |
| 17. Rendimiento y consumo | Medidas del sistema completo, con condiciones y unidades comparables. |
| 18. Escalabilidad | Dispositivos múltiples y reproducibilidad, con variación de fabricación y operación. |
| 19. Novedad | Comparación documentada con los antecedentes científicos más próximos. |
| 20. Contribución central | Resultado importante y sustentado por controles, distinto de una aspiración de impacto. |
| 21. Reproducción y revisión externas | Equipos independientes y revisión científica; una auditoría propia no las sustituye. |
| 22. Impacto sostenido | Uso y resultados posteriores de otros investigadores a lo largo del tiempo. |

Las simulaciones, el código y las auditorías pueden avanzar en esta ventana.
Las muestras, instrumentos y reproducción externa necesitan participantes
y recursos físicos; el impacto sostenido requiere además tiempo posterior.
Estos requisitos no se reemplazan por renders, datos sintéticos o una
declaración de calidad. La duración de doce horas no demuestra su cierre.
