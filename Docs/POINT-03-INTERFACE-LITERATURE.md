# Interfaces y alcance de los órdenes numéricos

Consulta de fuentes primarias el 7 de octubre de 2026, durante H2.
No cambia operador, geometría, detectores ni umbrales congelados.

[Vassallo, JOSAA 14,3273–3284 (1997)](https://opg.optica.org/josaa/abstract.cfm?uri=josaa-14-12-3273):
resumen del editor accesible; artículo completo no consultado. Distingue
error del stencil y de representar discontinuidades de índice; examina
fórmulas mejoradas y promedios de permitividad. No equivale a una prueba
para el potencial escalar linealizado ni la geometría T96. Aplicar otra
fórmula exigiría un nuevo modelo y ensayos; no se modifica H2.

[Henning y Peterseim, M3AS 27,2147–2184 (2017)](https://arxiv.org/html/1608.02267):
introducción, formulación y supuestos de regularidad R1–R3 consultados.
El método es Galerkin de elementos finitos y Crank–Nicolson conservativo.
Su análisis admite potenciales discontinuos con hipótesis explícitas,
y distingue tasas para potenciales suaves y abruptos. No es un teorema
para nuestro ADI, representación celular y absorbedor disipativo.
La ficha de publicación se contrastó con el editor y la página del autor;
la fecha renderizada del HTML no se interpreta como publicación nueva.

Inferencia local: el PASS de integración geométrica no demuestra que el
error óptico espacial desaparezca, ni que un orden alto de potencia sea
el orden del campo. La convergencia y sus predicciones requieren pruebas.
Estas fuentes motivan reservas y posibles formulaciones futuras; no
certifican resultados, Maxwell ni una muestra física de este proyecto.
