no se atribuyen a un servicio externo ni se inventa un identificador IPFS.
Se utiliza la parte aplicable de la habilidad de procedimiento científico
para datos inmutables, contraste y limitaciones. Este trabajo es un
informe de verificación numérica determinista, no un artículo publicado
en un corpus ni una prueba estadística con replicaciones aleatorias.

La revisión de convergencia sigue las cautelas de
[NASA](https://www.grc.nasa.gov/www/wind/valid/tutorial/spatconv.html):
las diferencias pequeñas entre mallas no bastan para establecer error
ni régimen asintótico. La referencia usa la acción exponencial de
[SciPy 1.15.1](https://docs.scipy.org/doc/scipy-1.15.1/reference/generated/scipy.sparse.linalg.expm_multiply.html),
que se contrasta con otro integrador y controles de solución conocida.
El futuro cierre, si procede, será local y condicional para potencia;
frontera, fase, Maxwell, perfiles medidos y fabricación tienen sus propios
hitos posteriores.
